🔄 sync-profile

把你的开发经验装进口袋，带到任意项目
这是做什么的？
一个 Skill，把你的个人侧写、AI 协作规则、踩坑记录打包成可跨环境复制的种子包。
解决了什么问题？
换项目时从头调教 AI，同样的坑在多个项目反复踩。

使用方式

先粘贴技能目录 sync-profile/ 到项目的 .claude/skills/ 下，然后在聊天框调用：

/sync-profile init  →  新项目初始化

/sync-profile pull  →  回收新经验回种子包

/sync-profile refresh  →  种子包更新同步到已有项目

目录说明

sync-profile/
├── profile/ ← 你这个人
│ ├── personal.md 技术栈、习惯、优势盲区
│ ├── coding.md 编码规范、命名风格、禁止项
│ └── workflow.md AI 协作规则、确认流程
├── config/ ← 全局配置模板
│ └── global-settings.json 权限规则、环境变量
├── knowledge/ ← 踩坑记录
│ ├── common/ 所有项目都带的通用经验
│ ├── rust/ 仅 Rust 项目
│ └── java/ 仅 Java 项目（可细分版本）
└── scaffolds/ ← 项目骨架模板
├── rust-tauri/
└── generic/

按语言过滤 初始化时只会复制匹配语言的踩坑记录。
按版本过滤 经验条目可标注适用版本，不匹配的跳过。

新项目初始化流程

1
AI 问项目语言类型（rust / java / node / other）
2
AI 问框架/版本（如 spring-boot-1.5）
3
只复制匹配语言和版本的踩坑记录到项目 docs/LESSONS.md
4
生成项目 CLAUDE.md 和 docs/ 骨架
5
全局 settings.json 合并权限配置

完成之后，AI 已经了解你的编码习惯、协作规则和常见踩坑。

跨环境流转

🏠 家里维护种子包 → 💾 复制到 U 盘 → 🏢 公司项目跑 init → 📥 pull 经验带回家

内网环境无需 git 无需联网，纯文件复制即可。
种子包本身即是 Skill 目录，整包复制、整包粘贴，不需要额外打包工具。

更详细的设计说明见 spec 文档。
任何运行中的问题直接问 AI。
