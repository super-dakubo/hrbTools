# 待办提醒展示与暂停功能 — 设计文档

## 概述

对待办面板进行两个优化：在列表中展示下次提醒时间的倒计时，以及增加暂停（推迟）提醒功能。

## 改动 1：待办列表展示提醒倒计时

### UI 展示

待办列表中的每个待办项，在文本和标签的右侧显示下次提醒时间的倒计时：

| 距离 | 显示 |
|------|------|
| 已过期（当前时间 ≥ 提醒时间） | `⏰ 已过期` |
| < 60 分钟 | `⏰ X分钟后` |
| < 24 小时 | `⏰ X小时后` |
| < 30 天 | `⏰ X天后` |
| ≥ 30 天 | `⏰ X个月后`（`Math.floor(天数 / 30)`） |

**规则：**
- 已完成或没有 `reminder` 的待办不显示
- 截止日期（`due_date`）不再展示在列表上
- 计算基于 `reminder.datetime`（格式 `%Y-%m-%dT%H:%M`）与当前时间的差值

### 样式

- 普通倒计时：使用主题强调色（`--accent`）
- 已过期：红色（`#ef4444`），类比现有 `.todo-due.overdue`

## 改动 2：暂停（推迟）提醒功能

### 数据模型

`TodoItem` 新增字段：

```rust
#[serde(default)]
paused: bool,
```

默认值 `false`，`#[serde(default)]` 保证旧数据兼容。

### 交互

- **点击倒计时文本** → 切换暂停状态
  - 暂停时显示 `⏸ X天后`（图标变暂停符号 `⏸`，倒计时照常计算）
  - 再点一次恢复正常
  - `⏰ 已过期` 状态不可交互，点击不切换暂停
- 暂停期间**不触发通知**（后端线程跳过 `paused: true` 的项）
- 无需在编辑弹窗中加暂停选项，纯列表交互

### 暂停到期行为

| 任务类型 | 原始提醒时间过了之后 |
|---------|-------------------|
| 非重复任务 | 自动清除 `paused=false` 并保存，显示 `⏰ 已过期` |
| 重复任务（每天/每周/每月） | 自动推到下一周期（同现有 `createNextRepeat` 逻辑），暂停状态保持 |

到期逻辑在前端 `renderTodos()` 中处理：渲染时比较 `reminder.datetime` 与当前时间，对非重复暂停项过期时清除 `paused` 并持久化。

### 后端逻辑

通知线程（`std::thread::spawn` 中的循环）：

```rust
// 跳过 paused 项
if todo.paused { continue; }
```

## 涉及文件

| 文件 | 改动 |
|------|------|
| `src/main.rs` | `TodoItem` 加 `paused` 字段；通知线程跳过暂停项 |
| `src/main.js` | `renderTodos()`：移除 `dueHtml`，添加 `reminderHtml`（倒计时计算 + 暂停交互）；点击倒计时切换 `t.paused` |
| `src/styles.css` | 加 `.todo-reminder`、`.todo-reminder.overdue`、`.todo-reminder.paused` 样式 |
